  1. Environnement virtuel. Vous allez utiliser le TP de programmation évènementiel dont le code est là : Arkanoid.zip.
    1. dézippez le projet et créez-vous un environnement virtuel dans le dossier projet
    2. ajoutez les modules pyglet et pytest à cet environnement en utilisant pip basé sur l'interpréteur de votre environnement virtuel
    3. vérifiez que les tests passent et que le code fonctionne avec votre environnement
    4. créez les fichiers :
      • requirements.txt qui explicite les dépendances
      • readme.md qui explicite comment exécuter le programme et le lien vers le cours.
  2. Dépôt :
    1. créez vous un compte github
    2. projet mettez le projet en ligne sur github (ne mettez pas l'environnement virtuel ni le dossier __pycache__ !)
  3. Gestion des sources avec github
  4. Partager des sources avec github
